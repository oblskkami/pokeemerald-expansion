================================================
 宝可梦 绿宝石（改版）  电脑版 操作说明
================================================

【怎么开始玩】
  1. 解压后保持 pokeemerald.exe 和 SDL2.dll 在同一个文件夹。
  2. 双击 pokeemerald.exe 即可，无需安装。
  3. 第一次运行会在同一文件夹生成存档文件 pokeemerald.sav。

【系统要求】
  Windows 7 / 8 / 10 / 11，32 位或 64 位都可以。
  如果提示缺少 SDL2.dll，说明解压时漏了它，请重新解压整个文件夹。

【键盘按键】
  方向键 ............ 移动 / 光标
  Z ................. A 键（确定、对话、调查、选招）
  X ................. B 键（取消、跑步）
  Enter ............. Start（打开菜单）
  \（反斜杠） ...... Select
  A ................. L 键
  S ................. R 键
  空格（按住） ...... 加速游戏
  +（加号） ......... 循环切换 1 倍 ~ 9 倍速度

  说明：空格是“按住才加速”，松开就恢复正常速度；
        + 号是把速度档位固定下来，再按继续往上跳，跳到 9 倍后回到 1 倍。

【手柄】
  支持 Xbox / XInput 等常见手柄，插上就能用：
  A / B 键 ......... 对应 A / B
  Start / Back ..... 对应 Start / Select
  LB / RB .......... 对应 L / R
  十字键、左摇杆 ... 移动

【窗口】
  窗口可以自由拖动边缘缩放，画面按整数倍放大，像素不会糊。
  退出：直接关闭窗口（或 Alt+F4）。

【存档】
  存档就是 exe 旁边那个 pokeemerald.sav。
  · 备份：把这个文件复制走即可。
  · 换机器：把 exe、SDL2.dll、pokeemerald.sav 三样一起拷过去。
  · 删档重来：删掉 pokeemerald.sav。
  注意：游戏里正常存档后才会写入这个文件，别在“正在保存…”时关窗口。

【遇到问题】
  如果游戏闪退，同一个文件夹里会出现 crash.log，把它发给作者即可定位。
  画面撕裂：可以在启动前设置环境变量 PE_VSYNC=1（开启垂直同步）。
  声音异常：可以试 PE_AUDIO_SAMPLES=512 与 PE_AUDIO_PREFILL=0 两个环境变量。
  （以上环境变量是给排查问题用的，正常玩不需要设置。）
